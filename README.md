# Štullers Social

Z jednej ilustrácie vygeneruje 3 nadväzujúce IG stories (1080 × 1920), carousel (1280 × 1600), animované video a print mockup. Všetko beží v prehliadači, nič sa nikam neodosiela.

**Appka:** https://peterstuller90-oss.github.io/stullers-social-media/

## Na telefón
- **iPhone (Safari):** otvor odkaz → Zdieľať → Pridať na plochu
- **Android (Chrome):** otvor odkaz → ⋮ → Inštalovať aplikáciu

## Súbory
- `index.html` – celá appka
- `manifest.webmanifest`, `sw.js`, `icons/` – inštalácia a offline režim (pri zmene appky zvýš `VERSION` v `sw.js`)
